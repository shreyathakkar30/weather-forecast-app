# 🌤 Weather Forecast App

A modern full-stack weather forecast application built using React, Node.js, Express, and OpenWeather API.

## 🚀 Live Demo

🔗 https://YOUR-VERCEL-LINK.vercel.app

---

## ✨ Features

- 🌍 Search weather by city
- 🌡 Real-time temperature
- 💧 Humidity information
- 💨 Wind speed details
- 🌤 Dynamic weather icons
- 🕒 Current date and time
- 📜 Recent search history
- 🎨 Dynamic gradient background
- ⏳ Loading animation
- 📱 Responsive UI
- 🔗 Social media links

---

## 🛠 Tech Stack

### Frontend
- React.js
- CSS3
- Axios

### Backend
- Node.js
- Express.js

### API
- OpenWeather API

### Deployment
- Vercel (Frontend)
- Render (Backend)
